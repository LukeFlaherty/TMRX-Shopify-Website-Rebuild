# Catalog observations

Public catalog reviewed November 10, 2026: **16 product identities**. The [machine-readable snapshot](catalog-observations.json) links each observed product page and maps its local source-media range. The price examples are public-page observations, not an authenticated feed or a production price list. Recheck current variant, market, stock and label before implementation.

The product source library contains the supplied original images, including front/alternate views and labels. Its primary-image candidates are starting points for visual QA, not automatic variant binding. Some internal file names differ from current display names: `true-omega` is displayed publicly as Premium Omega 180, `true-greens` as Supergreens, and `true-creatine` as CREATINE 400G (micronized). Keep actual Shopify handles; let visible capitalization come from an approved display rule.

The primary candidates were visually inspected in `qa/product-source-contact-sheet.jpg`. They include third-party-branded Myos MD and N1O1 packaging; do not redraw those into True Matrx containers as a generated concept might. Secretropin has only a 265 × 503px original, which is specifically marked as a large-gallery input gap. No source was upscaled to conceal the limitation.

Availability is intentionally not certified. Public extracted product templates sometimes include both generic Sold out and Add to cart text. Variant-level availability requires current Shopify data. No ingredients, dose or warning is inferred from a product name or generated screenshot.

## Product format implications

Powders need appropriate mixing/directions media; capsules/softgels need their own use information; Secretropin and N1O1 need spray/lozenge-specific information. Mito-Revive and Vitamin D+K2 show capsules on the supplied original front images; these format hints still require current-variant verification. These are content requirements, not new health recommendations. Product warnings and directions should be approved independently of this visual package.
