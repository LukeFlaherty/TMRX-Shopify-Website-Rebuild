# V3 changelog

## 3.0.0 — 2026-11-10

Established the V3 design package from the selected A direction and subsequent mobile spacing feedback. Added new page-owned photography, fresh mockups, authentic brand/product source exceptions, route/spec registry, design tokens, component/state contracts, research ledger, product snapshot, asset provenance and integrity checks, offline visual index and a distributable archive. Future changes must increment the package version, update affected page/asset records, record review caveats, rerun the package validator, and preserve provenance of replaced assets. Do not silently overwrite approved originals; add a new versioned asset or explicitly record the replacement.
