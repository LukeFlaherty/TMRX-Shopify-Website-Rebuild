# V3 changelog

## 3.1.0 — 2026-11-12

Added 12 product-included variants A15–A26 and made them preferred for their mapped slots, retaining original plates as alternate source material. Added six cart references M13–M18 covering desktop/phone drawer and full page, recommendation controls and empty/error/adding states. Expanded cart specifications to require visual recommendations, real variant selection and cart updates without page reload; added 22 future functional acceptance scenarios.

Added a 92-task dependency-based development roadmap across 13 phases, with individual checks for all 16 product groups and coverage of all 22 page/surface briefs. Explicitly distinguished V1 live, V2 partial existing draft and V3 redesign. Updated page mappings, asset/catalog tooling, source evidence, visual caveats and package validation. This revision changes design assets and documentation only; no theme code or Shopify deployment.

## 3.0.0 — 2026-11-10

Established the V3 design package from the selected A direction and subsequent mobile spacing feedback. Added new page-owned photography, fresh mockups, authentic brand/product source exceptions, route/spec registry, design tokens, component/state contracts, research ledger, product snapshot, asset provenance and integrity checks, offline visual index and a distributable archive. Existing Shopify theme source and draft were not modified or deployed.

Future changes must increment the package version, update affected page/asset records, record review caveats, rerun the package validator, and preserve provenance of replaced assets. Do not silently overwrite approved originals; add a new versioned asset or explicitly record the replacement.
